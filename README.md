# QuizBlast - Multiplayer Quiz Game

live demo - https://quiz-blast-co.vercel.app/

QuizBlast is a real-time multiplayer quiz game inspired by platforms like Kahoot. Players can join a room, answer questions, compete live, and view rankings instantly.

---

## Features

- 🎮 Multiplayer quiz rooms
- ⏱️ Timed questions
- 📊 Live leaderboard
- 👥 Join with room code
- ✏️ Rename player before joining
- 🏆 Final podium results
- ⚡ Fast and responsive UI (React + Vite)

---

## Tech Stack

- React.js (Frontend)
- Vite (Build tool)
- Firebase Realtime Database (for multiplayer sync)
- CSS (UI styling)
